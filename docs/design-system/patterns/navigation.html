Pattern

Navigation

Five screens and no menus. Each screen leads to the next with one button, and the header never lists places to go.

Overview

Telo Ride 1 is one class, start to finish, so there is nothing to navigate between. The screens form a line: a new rider opens on Connect Bike and lands on The Class once paired; a returning rider opens on The Class. From there one button starts the ride and the ride ends on Class Done, whose one button returns to The Class.

  1. Connect Bikea new rider starts here; the bike is remembered
  2. The Classhome; one start button
  3. Ibiza Flyoverbefore a ride in Ibiza only
  4. Class Ridecountdown, the class, finish banner, roll-out
  5. Class DoneDone returns to The Class

The routes are /connect, /, /ride (Ibiza Flyover, then Class Ride) and /done. Any other address shows Page not found.

When to use what

To goThe rider presses
Connect Bike → The ClassPair; it lands on The Class when paired.
The Class → Connect BikeThe bike link in the header (“· Change”, or “No bike · Connect”), or the start button when it reads “Connect your bike”.
The Class → a rideThe start button.
Ibiza Flyover → The ClassCancel.
Ibiza Flyover → Class RideSkip flyover, or wait.
Class Ride → The ClassLeave class.
Class Ride → Class DoneNothing: it opens on its own after the roll-out.
Class Done → The ClassDone.
Page not found → The ClassBack to the class.

Structure

Every screen has the same frame: a skip link, the header with the lockup and the screen’s own controls, and one <main>.

States

  • No bike: The Class still shows; its start button becomes the way to Connect Bike.
  • Unsupported browser or no HTTPS: the rider can look around but not ride; the browser notice says so.
  • Finish and roll-out: Pause and Leave are gone from the header; Class Done is seconds away.

Responsive behaviour

The frame is the same at every size. On The Class the start button is in the side column from 1024px and pinned to the foot below it; the header’s “· Change” hides from sight below 640px but is still read.

Accessibility

  • The skip link is first on every screen and goes to #main.
  • Each screen has one <h1>; Class Ride’s is visually hidden.
  • Each screen’s document title names the screen.
  • There is no <nav> landmark, because there is no navigation.

Content

  • The screens are Connect Bike, The Class, Ibiza Flyover, Class Ride and Class Done. No “Home”.
  • A button that moves on names the next thing: “Start class”, “Skip flyover”, “Done”, “Back to the class”.
