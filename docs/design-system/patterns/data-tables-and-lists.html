Pattern

Data tables and lists

Small sets, shown whole: five bikes, three stats, four facts, seventeen efforts. No tables, no paging.

WCAG 2.2 AAStatus: stable

Overview

The data in Telo Ride 1 is the bike’s live numbers, the rider’s record and one ride’s result. None of it is long enough to sort, filter or page, so each set is drawn in the shape that suits it and marked up as the list it is.

States

  • No record yet: the stats are not drawn.
  • Every effort at 0 W: the chart shows the figures with no bars.
  • Nothing loads: the class ships with the app.

Responsive behaviour

  • Works with is one column, two from 640px.
  • The stats are three equal columns; the facts wrap.
  • At 320px the efforts’ figures stand upright along their bars.

Accessibility

  • Use the real list element, so the count is announced.
  • A chart’s every value is text; the strongest effort says so in words.
  • Values carry their units in their own text.

Content

  • Status words, not icons alone: “Full control”, “Beta”.
  • Labels of one or two words; values with units.
