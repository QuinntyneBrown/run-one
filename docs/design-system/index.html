Design system

Telo Ride 1 design system

Telo Ride 1 is one class, start to finish: connect the bike, take Intervals to the Beat, see your output, and come back to beat it. This is its visual and interaction language, extracted from the mocks of its five screens: Connect Bike, The Class, Ibiza Flyover, Class Ride and Class Done.

How to use

  1. Link tokens/tokens.css, then assets/components.css. Set data-theme="dark" or "light" on <html>, or leave it off to follow the device.
  2. Use the classes as each component page’s Code section shows them. Keep the BEM names: the product’s e2e locators depend on them.
  3. Read tokens by role in new CSS; never a hex, a raw length or a palette token.
  4. Tools consume tokens/tokens.json (DTCG). The app keeps its own copy of the tokens at frontend/projects/ride/src/styles/tokens.css; a token added here is added there in the same change.
  5. Before a screen is built or changed, draw its states in the mocks, then bring this system in line, then the code.
