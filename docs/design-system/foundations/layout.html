Foundation

Layout

Five screens, each a full-height shell. The Class fits an 11-inch tablet in landscape with no scrolling; portrait is one column that scrolls.

Overview

Every screen is a column as tall as the window (.app): a header, then one region that either scrolls or is laid out to fit. There is no sidebar, no navigation and no page grid shared between screens: each screen’s layout is its own block, built from the tokens below. See Container for the shell’s classes.

Columns, gutters, margins

The column grid is 4 columns below 768px, 8 from 768px and 12 from 1024px. Gutters are 16px, 24px from 768px and 32px from 1024px; the margin from the window’s edge is 16px, 24px from 640px and 32px from 1024px. The tokens change at those widths; components read them.

The shape of a ride

Ibiza Flyover is the course edge to edge between a bar and a band, so no word lies on the course. On Class Ride the countdown, the finish banner and the roll-out lie inside the video’s or the course’s box, above the bike panel and its stepper; Class Ride keeps its layout through all of them. See The shape of a ride.

Usage

  • A screen fits or scrolls as one; never nest a scrolling region inside a scrolling page.
  • Anything pinned to the foot keeps clear of the home bar with env(safe-area-inset-bottom).
  • A fixed side column takes its width from a token (--the-class-aside-width), and the rest is minmax(0, 1fr).
  • Text blocks keep a measure: --layout-text-* for cards and notices, --layout-measure for prose.
