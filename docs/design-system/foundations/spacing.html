Foundation

Spacing

One scale on a 4px grid, for the space inside components and between them.

WCAG 2.2 AAStatus: stable
  • Overview
  • Scale
  • Usage
  • Tokens

Overview

Every gap, padding and fixed size is a step of one scale. Whole steps are multiples of 4px; half steps (2, 6, 10, 14px) exist for tight insides like a pill’s padding. Nothing uses a raw length.

Usage

  • Inside a component: 8 to 16px. The bike panel’s cells are 12 × 16px; a button’s side padding is 16px.
  • Between components in a group: 12px (the bike panel’s grid, Class Ride’s stage). Between groups: 24 to 32px. Between a screen’s regions: 40px and up.
  • A notice stands 8px under its subject, closer than the 12px between neighbours, so it reads as belonging to it.
  • Screen edges use --layout-margin, not a spacing step: see Layout.
