Error page

A whole page that says what went wrong and offers one way back: Telo Ride 1 has one, Page not found.

WCAG 2.2 AAStatus: stableIn the mocks

Overview

An address that is not one of the app’s routes shows Page not found (L2-145): a title, one sentence and one button back to the class. It keeps the header, so the rider still knows where they are.

A class that cannot be loaded is not an error page: The Class keeps its header and shows one inline message over Reload.

Anatomy

Page not foundpages/not-found/default
  1. Title“This page doesn’t exist.” The page’s <h1>, 24px semibold.
  2. LeadWhy it may have happened, and that nothing is lost: “Your rides are safe.”
  3. ActionA primary large button, 32px under the lead: “Back to the class”.

Variants

One error page. The system does not draw 403, 500 or offline pages: the app has no backend, and a ride finishes on the device without a network.

Sizes

One size.

States

The page has one state.

Responsive behaviour

The text keeps a measure of 576px and stays aligned with the header’s left edge at every width; the button never stretches.

Theming

Page colours only.
