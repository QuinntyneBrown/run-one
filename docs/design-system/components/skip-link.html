Skip link

The first thing a keyboard reaches on every screen: a link that jumps past the header to the content.

Overview

Every screen starts with <a class="skip-link" href="#main">Skip to content</a>. It is off screen until it takes focus, then it shows in the top-left corner over everything.

Anatomy

  1. LinkThe accent fill with ink text, 8px radius, 14px semibold; it slides in from above when focused.
