Chip

A compact tag, sometimes removable.

Overview

A chip marks a value the rider has chosen or can remove.

Where Telo Ride 1 stands: nothing is filtered or tagged: one class, one course. No screen uses a chip.

Anatomy

  1. ChipRaised fill, full radius, 12px medium.
  2. RemoveOptional: a labelled button after the text.

Sizes

One size.

States

A static chip has no states; its remove button takes the icon button’s.

Responsive behaviour

It takes the width of its container and has no breakpoints of its own.

Theming

It reads semantic tokens only, so it follows the theme with no rule of its own.

Accessibility

Role and pattern

Text; the remove control is a real <button>.

Keyboard

EnterRemoves the chip

Focus

The standard focus ring: 2px --color-focus-ring, 2px off the control.

Labelling

The remove button’s name includes the chip’s text: “Remove Sprints”.
