Pagination

Moving through a long list a page at a time.

Overview

Pagination splits a list too long for one page.

Where Telo Ride 1 stands: no list is long enough: the class has 17 efforts and the app keeps a ride count, a best and a last output, not a history.

Anatomy

  1. Previous / NextSteps with an arrow and a word; at an end the step is aria-disabled.
  2. PageA 36px square; the current page is filled and has aria-current="page".

Accessibility

Role and pattern

<nav aria-label> holding a list of links.

Keyboard

KeyAction
TabLink to link
EnterGoes to the page

Focus

The standard focus ring: 2px --color-focus-ring, 2px off the control.

Labelling

Each page link is named “Page 2”; the steps are named “Previous page” and “Next page”.

Contrast

Motion

State changes fade over --duration-fast; reduced motion makes them instant.

Touch

Targets are at least 44 × 44px.

Content

  • Say what is shown: “1–10 of 23 rides”.
