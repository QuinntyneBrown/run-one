Textarea

Several lines of typed text.

Overview

A textarea is the text field for an answer that may run to a few sentences.

Where Telo Ride 1 stands: nothing uses it: the diagnostic note is one line.

Anatomy

  1. BoxThe text field’s box, at least two rows tall.
  2. Text14px, wrapping.

Variants

Three rows.
HTML
<textarea class="input ds-w-md" rows="3" aria-label="Note">bike shows 82 rpm, resistance 14</textarea>

Sizes

One size.

States

StateDefaultFocusInvalidDisabled
Textarea

Responsive behaviour

It takes the width of its container and has no breakpoints of its own.

Theming

It reads semantic tokens only, so it follows the theme with no rule of its own.

Accessibility

Role and pattern

A native <textarea>.

Keyboard

KeyAction
TabMoves to and from the field
EnterAdds a line

Focus

The standard focus ring: 2px --color-focus-ring, 2px off the control.

Labelling

As a text field: a visible label, errors by aria-describedby.

Contrast

light theme
Text in the field
dark theme
Text in the field

Motion

State changes fade over --duration-fast; reduced motion makes them instant.

Touch

Targets are at least 44 × 44px.

Content

  • Ask one question per textarea.
  • If there is a limit, show the count.
