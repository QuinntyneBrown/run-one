Skeleton

Grey shapes that hold the place of content while it loads.

WCAG 2.2 AAStatus: stableCore set · no Telo Ride 1 screen uses it yet

Overview

A skeleton shows the shape of what is coming, so the page does not jump when it arrives.

Where Telo Ride 1 stands: the class ships with the app, so The Class has nothing to wait for. The two waits there are say so in words: “Loading Ibiza Sunset Strip” and the pairing card’s spinner. No screen uses a skeleton.

Anatomy

  1. ShapeRaised fill, 6px radius, pulsing.
  2. Containeraria-busy="true" and a name; the shapes themselves are hidden.

Variants

A title and two lines.
HTML
<div class="ds-w-md" role="status" aria-label="Loading the class" aria-busy="true"><div class="skeleton-stack" aria-hidden="true"><span class="skeleton skeleton--title"></span><span class="skeleton skeleton--text"></span><span class="skeleton skeleton--text" style="--skeleton-width: 60%"></span></div></div>
Circle, button and numeral.
HTML
<div class="ds-row" aria-hidden="true"><span class="skeleton skeleton--circle"></span><span class="skeleton skeleton--button"></span><span class="skeleton skeleton--numeral"></span></div>

Sizes

One size.

States

A skeleton is a state: loading.

Responsive behaviour

It takes the width of its container and has no breakpoints of its own.

Theming

It reads semantic tokens only, so it follows the theme with no rule of its own.

Accessibility

Role and pattern

The shapes are aria-hidden; the container is a role="status" named for what loads.

Keyboard

None.

Focus

It takes no focus.

Labelling

Name what is loading: “Loading the class”.

Contrast

light theme
Shape on the page (decorative)
dark theme
Shape on the page (decorative)

Motion

It pulses to 55% opacity over --duration-pulse. With reduced motion it is still.

Touch

Nothing is pressed.

Content

A skeleton has no words of its own; its container’s name is “Loading” and the thing.
