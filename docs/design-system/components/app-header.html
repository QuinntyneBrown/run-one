App header

The slim header of every screen: the lockup, what this screen is about, and its few controls. There is no navigation in it, because there are no menus.

Overview

Telo Ride 1 has five screens and no menus, so the header (.class-header) never lists places to go. It carries the lockup, one line of context, and the controls that belong to the screen: the bike on The Class; the clock, Pause and Leave on Class Ride; Full screen everywhere.

Ibiza Flyover has a bar of its own (see Ibiza Flyover).

Anatomy

  1. LockupTELO RIDE 1. On Class Ride the wordmark is 20px and hides below 384px, leaving the mark.
  2. ContextClass Ride: the class’s name and “· Solo”, from 768px. Class Done: the class’s name. The Class: nothing.
  3. ClockClass Ride only: the display face, 24px, tabular; role="timer". “/ 20:00” shows from 640px.
  4. ControlsPause or Resume (a raised small button; its label shows from 640px), Leave (an icon button that turns to the danger colour on hover) and Full screen.
  5. RuleA hairline under the header.

Responsive behaviour

  • Padding: 16px at the sides, 24px from 640px, 32px from 1024px (24px on Class Ride).
  • The Class, below 640px: “· Change” is hidden from sight but still read, so the bike link says what it does.
  • Class Ride: below 384px the wordmark hides; below 640px Pause shows its icon alone and the clock drops “/ 20:00”; the class’s name shows from 768px.

Theming

The header stands on the page background with a --color-line rule. The connected bike’s icon is --color-volt-fg; with no bike it is --color-heart-fg.

Accessibility

Role and pattern

A <header> landmark. It holds no <nav>: there is nowhere to navigate.

Keyboard

KeyAction
TabThe bike link or Pause, Leave, then Full screen
EnterFollows the link or presses the button
SpacePresses the focused button

Focus

The standard ring. On Class Ride the header stays above the lost-bike alert, so Leave and Full screen stay in reach (L2-092 AC2).

Labelling

The lockup is one image named “Telo Ride 1”. Icon-only controls are named: “Leave class”, “Full screen”. The clock’s name gives both times: “5:30 of 20:00”.

Motion

Hover fills fade over --duration-fast.

Touch

The bike link is 44px tall. On Class Ride Pause and Leave are 48px squares below 640px; from 640px each control takes touches across 44px.

Content

  • The bike link: “Echelon EX-5s · Change” or “No bike · Connect”.
  • “Pause” and “Resume”; “Leave class”; “Full screen”.
  • The mode is always “· Solo”: a ride is never anything else.
