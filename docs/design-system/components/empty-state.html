Empty state

What a place shows when it has nothing to show yet.

WCAG 2.2 AAStatus: stableCore set · no Telo Ride 1 screen uses it yet

Overview

An empty state says why there is nothing here and offers the one thing to do about it.

Where Telo Ride 1 stands: no screen can be empty. A new rider starts on Connect Bike, which is a screen of its own, not an empty state; The Class with no bike changes its one button to “Connect your bike”; a first Class Done says “Class done. That’s your number to beat.”

Anatomy

  1. Icon32px, muted.
  2. TitleWhat is missing, 18px semibold.
  3. BodyOne sentence: why, and what to do.
  4. ActionOne primary button.
