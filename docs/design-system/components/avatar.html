Avatar

A small mark that stands for a person.

Overview

An avatar stands for a person where a name alone is not enough.

Where Telo Ride 1 stands: there is no sign-in and a ride is always solo, so no screen shows a person. An avatar would need an account, which ADR 0039 rules out; it stays in the core set only.

Anatomy

  1. Disc32px, full radius, raised fill.
  2. InitialOne or two letters, 12px semibold.

States

An avatar has no states.

Responsive behaviour

It takes the width of its container and has no breakpoints of its own.

Theming

It reads semantic tokens only, so it follows the theme with no rule of its own.

Accessibility

Role and pattern

Decorative beside a name (aria-hidden); role="img" with a name when it stands alone.

Keyboard

None.

Focus

It takes no focus.

Labelling
