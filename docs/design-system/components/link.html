Link

An inline text link: underlined, in the accent, inside a sentence.

Overview

A link goes somewhere; a button does something. .link is the link inside running text.

Where Telo Ride 1 stands: the app’s screens have no inline links yet: every move between screens is a button, and the header’s bike link has its own block (see App header).

Anatomy

  1. TextThe words that name where it goes, in --color-fg-link.
  2. UnderlineAlways drawn, 0.15em under the text: colour is never the only sign of a link.

Accessibility

Role and pattern

A real <a href>.

Keyboard

KeyAction

EnterFollows it

Focus

The standard focus ring: 2px --color-focus-ring, 2px off the control.

Labelling

The link’s text says where it goes without the words around it. A link that opens a new tab says so in its text.

Motion

State changes fade over --duration-fast; reduced motion makes them instant.

Touch

Inline links follow the text’s line height; a link that stands alone is a button or gets 44px of height.

Content

  • Name the destination: “how pairing works”, not “click here”.
  • Sentence case; no full stop inside the link.
