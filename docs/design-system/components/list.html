List

Overview

A list shows items of one kind, each with a title and perhaps a line of detail.

Where Telo Ride 1 stands: the “Works with” list on Connect Bike has its own block (see Device list), and the efforts are Class Done’s chart. No screen uses the generic .list.

Anatomy

  1. ItemAt least 44px tall when it can be pressed.
  2. Title14px medium.
  3. Detail12px, muted, under the title.

Sizes

One size.

States

A static list has no states; an item that can be pressed is a link or a button and takes theirs.

Responsive behaviour

It takes the width of its container and has no breakpoints of its own.

Theming

It reads semantic tokens only, so it follows the theme with no rule of its own.

Accessibility

Role and pattern

A <ul>, or an <ol> when order matters.

Keyboard

None for a static list.

Focus

The standard focus ring: 2px --color-focus-ring, 2px off the control.

Labelling

An interactive item is a real link or button inside the <li>.

Contrast

light theme
Text on the page
Muted text on the page
dark theme
Text on the page
Muted text on the page

Motion

State changes fade over --duration-fast; reduced motion makes them instant.

Touch

Targets are at least 44 × 44px.

Content

  • Lead with the word that tells items apart.
  • Keep items parallel.
