Overview

Tabs switch between cuts of one set without leaving the page.

Where Telo Ride 1 stands: no screen has tabs: each shows one thing. They stay in the core set.

Anatomy

  1. Listrole="tablist" with a name; a hairline under it.
  2. Tab14px medium; the selected one has a 2px bar in the accent and full-strength text.
  3. CountOptional, in a raised pill with tabular numerals.

Variants

Underline tabs with counts.
HTML
<div class="tabs ds-w-md"><div class="tabs__list" role="tablist" aria-label="Efforts (specimen)"><button class="tabs__tab" type="button" role="tab" aria-selected="true">All <span class="tabs__count">17</span></button><button class="tabs__tab" type="button" role="tab" aria-selected="false" tabindex="-1">Sprints <span class="tabs__count">5</span></button></div></div>

Sizes

One size.

States

StateDefaultHoverFocusDisabled
Second tab

Responsive behaviour

Tabs never wrap. A list wider than its container scrolls sideways and fades its trailing edge (.tabs--scroll).

Theming

It reads semantic tokens only, so it follows the theme with no rule of its own.

Accessibility

Role and pattern

APG Tabs with automatic activation: arrows move and select.

Keyboard

KeyAction
TabInto the selected tab, then on to its panel
← →Previous and next tab
Home EndFirst and last tab

Focus

The standard focus ring: 2px --color-focus-ring, 2px off the control.

Labelling

The list has an aria-label; each tab controls a role="tabpanel".

Motion

State changes fade over --duration-fast; reduced motion makes them instant.

Touch

Targets are at least 44 × 44px.

Content

  • One or two words per tab; the same grammar across the set.
