Overview

A breadcrumb shows where a page sits in a hierarchy and offers the way back up.

Where Telo Ride 1 stands: the app is five screens in a line, not a tree, so nothing has a breadcrumb. Class Ride’s way back is Leave; Class Done’s is Done.

Anatomy

  1. LinkA parent page, muted; underlined on hover.
  2. SeparatorA chevron, hidden from assistive technology.
  3. CurrentThis page’s name, full strength, not a link, with aria-current="page".
