Overview

A table is for values read against each other, by row and by column.

Where Telo Ride 1 stands: Class Done draws the 17 efforts as a bar chart whose markup is an ordered list, each item with its watts in text; there is no table on any screen.

Anatomy

  1. CaptionNames the table; always present.
  2. Header row12px, muted; scope="col".
  3. Row headerThe first cell of each row, scope="row".
  4. NumbersRight-aligned, tabular (.table__num).

Responsive behaviour

A table wider than its container scrolls sideways inside .table-wrap; the page never scrolls sideways.

Theming

It reads semantic tokens only, so it follows the theme with no rule of its own.

Accessibility

Role and pattern

A native <table> with a <caption> and scoped headers, in a focusable scrolling region.

Keyboard

KeyAction
TabTo the region, then to any control in it
← →Scroll the region when it is wider than its container

Focus

The standard focus ring: 2px --color-focus-ring, 2px off the control.

Labelling

The region’s aria-label repeats the caption.

Contrast

light theme
Text on the page
Muted text on the page
dark theme
Text on the page
Muted text on the page

Motion

State changes fade over --duration-fast; reduced motion makes them instant.

Touch

Targets are at least 44 × 44px.

Content

  • Units in the cells, as everywhere: “417 W”.
  • Column headers are nouns.
