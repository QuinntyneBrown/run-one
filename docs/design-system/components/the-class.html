The Class

The home screen and the only class: its video, what it is, how long, how to ride it, what the bike will do, and one start button.

Overview

The Class (.the-class) is where Telo Ride 1 opens for a returning rider, and where a new rider lands once the bike is paired. It shows Intervals to the Beat (GCN Training, 20:00): the video, the title and summary, Ride with, the length, the plan chart and one start button. A returning rider also sees their ride count, best output and last output (stats).

It is a screen, documented here as one block because its layout is the design: on an 11-inch tablet in landscape and on a desktop it fits one screen with no scrolling.

Responsive behaviour

  • Phone and tablet in portrait (below 1024px): one column that scrolls: video, class, Ride with, length and stats, plan. The start button is pinned under the scrolling page, clear of the home bar. On a phone the three stats wrap under “20:00”; on a portrait tablet they sit beside it; Ride with is two columns from 640px.
  • 11-inch tablet in landscape (1194 × 834) and desktop (from 1024px): one screen, no scrolling. A fixed side column (380px, 420px from 1280px) holds the class and the start button; the video takes the height that is left and stays 16:9; the plan sits under the video.
  • A window under 800px tall (1024 × 768): the same parts drawn tighter, so every state still fits. A window too short even for that scrolls rather than cut anything off.
The same mock in this page’s width: resize the window to see the layouts.pages/the-class/returning

Theming

The page is --color-ink; the pinned footer is --color-ink with a hairline above. The disabled start button uses the raised fill and faint text instead of a dimmed accent, so it does not read as a broken primary.

Accessibility

Role and pattern

A page with a <header> and a <main>. The class’s title is the <h1>; “Ride with” and “What the bike will do” are <h2>s. The stats are a <dl>.

Keyboard

KeyAction
TabThe bike link, Full screen, Ride with (one stop), the start button
← →Move the Ride with choice
EnterStarts the class

Focus

Below 1024px the start button is drawn twice (in the flow and pinned); only the visible one is in the tab order and the accessibility tree.

Labelling

A blocked start says why in text under it: “The class needs the bike to set resistance.” The browser notice is a role="alert".

Motion

None of its own. The video does not autoplay.

Touch

The start button is 56px tall; Ride with options are 44px or taller.

Content

  • The button: “Start class”, “Ride it again”, “Connect your bike”.
  • “20:00 start to finish”. Stats: “Rides”, “Best output”, “Last time”, in kJ.
  • One sentence for the class: “Seventeen efforts from 15 seconds to 1:15, ridden to the beat, with five fast sprints to finish.”
