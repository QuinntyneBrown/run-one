Overview

A sidebar lists the sections of a product that has many.

Where Telo Ride 1 stands: there is no navigation. Five screens follow one another (Connect Bike, The Class, Ibiza Flyover, Class Ride, Class Done) and no screen lists the others. A sidebar would work against that direction; it stays in the core set for the day the product is given sections, which needs a requirement and a mock first.

Anatomy

  1. LinkAn icon and a label, 40px tall, 8px radius.
  2. Currentaria-current="page": a raised fill, a bar in the accent, and full-strength text.

Role and pattern

A <nav> with an aria-label, holding a list of links; the current one has aria-current="page".
